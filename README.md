# Оптимизация муравьиной колонии — Java Swing

Оконное приложение на Java для демонстрации алгоритма муравьиной колонии (Ant System) на задаче коммивояжёра.

## Требования

- JDK 17 или новее (не только JRE).
- Сторонние библиотеки не нужны: интерфейс построен на Swing.

## Управление

- **Старт** — запускает анимацию.
- **Пауза** — приостанавливает анимацию.
- **Шаг** — перемещает каждого муравья на одну дорогу.
- **Сброс** — начинает эксперимент заново и применяет выбранное число итераций.
- Кнопки **0, 2, 4, 6, 8, 10** меняют скорость. Ноль означает самую медленную анимацию; остановка выполняется кнопкой «Пауза».
- Наведение курсора на дорогу показывает её длину и количество феромона.

## Параметры демонстрации

Граф состоит из шести городов и пятнадцати двунаправленных дорог. Шесть дорог внешнего контура имеют длину 10, диагонали — 24. Кратчайший замкнутый маршрут имеет длину 60.

В первой итерации влияние расстояния временно равно нулю, поэтому среди непосещённых городов действует равновероятный случайный выбор. Затем влияние феромона и расстояния плавно увеличивается в течение первых шести итераций. Это делает переход от разведки к предпочтению коротких дорог менее резким, чем при прежнем значении β = 4.

Вероятность выбора следующего города:

`P(i -> j) = tau(i,j)^alpha * (1 / distance(i,j))^beta / sum(...)`

После каждого полного цикла:

1. На всех дорогах испаряется феромон: `tau = tau * (1 - rho)`.
2. Каждый муравей добавляет `Q / Lk` на дороги собственного замкнутого маршрута.
3. Сохраняется лучший найденный маршрут.

Когда заданное число итераций завершено, муравьи продолжают двигаться по лучшему найденному циклу, чтобы результат был наглядно виден.

## Структура проекта

Исходные файлы собраны в одной папке `src/antcolony` — без вложенных каталогов `main/java` и без отдельной папки `test`:

- `Main.java` — запуск приложения.
- `MainFrame.java` — главное окно и управление.
- `GraphPanel.java` — отрисовка графа, дорог, феромона и силуэтов муравьёв.
- `Node.java` — город (узел графа).
- `Edge.java` — дорога (ребро графа).
- `Graph.java` — сеть городов и дорог.
- `Ant.java` — отдельный муравей и его маршрут.
- `AntColonyConfig.java` — параметры алгоритма.
- `AntColony.java` — выбор следующего города, движение, испарение и обновление феромона.
